# Sketch to Art Generator

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Dhanush-HM/sketch-2-art-generator/blob/main/Sketch2Art.ipynb)

A Generative AI project that transforms sketches into artistic images using Stable Diffusion and ControlNet.

## Technologies Used

- Python
- PyTorch
- Diffusers
- Transformers
- Stable Diffusion
- ControlNet
- Google Colab
